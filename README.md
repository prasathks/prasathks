### 🚀 Featured Projects

#### 🏛️ [CiviCore – Smart Civic Operations & Waste Management Platform](https://github.com/prasathks)
*An end-to-end municipal governance and civic complaint resolution platform connecting citizens with municipal authorities.*
- **Tech Stack:** `Java` • `Spring Boot` • `Spring Data JPA / Hibernate` • `REST APIs` • `JavaScript` • `MySQL`
- **Key Features:**
  - Automated complaint registration, geotagged issue categorization, and dynamic department assignment.
  - Transparent verification pipelines with status tracking and automated **SLA escalation triggers** for unresolved issues.
  - Role-based access control (RBAC) separating citizen portals, municipal field workers, and administrative supervisory dashboards.

---

#### 📚 [LibReserve – Smart Library Fine & Priority Reservation System](https://github.com/prasathks)
*An intelligent library management engine optimizing inventory turnover, user borrowing limits, and priority-driven resource queueing.*
- **Tech Stack:** `Java` • `Node.js` • `HTML5` • `CSS3` • `MySQL`
- **Key Features:**
  - Priority-based waitlist algorithm that computes urgency and availability to allocate returned books dynamically.
  - Automated fine calculation engine with borrowing limit enforcements and instant return-status reconciliation.
  - Intuitive catalog search and reservation interface improving book discovery and reducing hold-time bottlenecks.

---

#### ⚡ [NexQ — Real-Time Digital Queue Intelligence System](https://github.com/prasathks)
*A high-throughput queue orchestration system for high-volume service environments (clinics, banking halls, and service centers).*
- **Tech Stack:** `Java` • `Spring Boot` • `JWT` • `Hibernate` • `WebSocket` • `MySQL`
- **Key Features:**
  - Concurrency-safe FIFO token distribution with thread-safe counter synchronization.
  - Instant bi-directional "Now Serving" counter broadcasts using WebSocket protocols.
